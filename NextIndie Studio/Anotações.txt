Caminho para alterar o tamanho e orientação da viewport: Projeto -> Configurações do projeto -> Janela -> Tamanho e Portátil

Atalho para alterar nome de nó: F2 com nó selecionado

Adicionar um background em sua cena: Criar um nó Sprite2D e colocar a imagem de fundo com sua textura 

Para uma fase, um Node2D funciona bem como um nó raiz, mas, para uma cena Player, podemos usar o nó CharacterBody2D como nó raiz

Aviso no CharacterBody2D: significa que nele precisa ser adicionado um shape - nó filho CollisionShape2D

Configuração do CollisionShape2D: Shape -> Escolhar formato mais adequado

Exemplos de cenas: jogador, inimigo, fase, tela de vitória, tela game over, menu

Exemplo de cena jogador: nó raiz CharacterBody2D, nós filhos: Sprite2D (carrega o sprite), CollisionShape (determina a área de colisão), Timer (cronômetro para funções diversas)

Podemos usar cenas dentro de cenas, exemplo: cena Fase: nó raiz Node2D, nós filhos: Jogador, Inimigo, Item (todas são cenas que tem seus respectivos nós raízes e filhos)

Atalho para instanciar cena filha: Crtl Shift A

Tipos de nós de corpos físicos: StaticBody2D (usado para corpos estáticos, como cenário ou plataformas), CharacterBody2D (usado para personagens, como o player ou inimigos) e RigidBody2D (partes do cenário afetados por simulação física)

Dentro dos nós de corpos físicos, deve haver um nó filho CollisionShape2D com sua colisão definida

O nó Area2D é uma forma de detectar caso uma fase termine, por exemplo, é como um StaticBody2D, também precisa de uma colisão, mas, quando interage com algum corpo, pode implicar em algum evento no jogo

É possível acessar variáveis entre scripts de nós irmãos do seguinte modo: variavel = get_parent().get_node('Nó')

Caminho para verificar mapa de entrada de teclas: Projeto -> Configurações do projeto -> Mapa de entrada -> Mostrar ações integradas

Para selecionar valores aleatórios dentro de um array: pick_random()

Definir movimento de objetos após uma colisão: velocity = velocity.bounce(colisao.get_normal())

Identificar com qual objeto uma colisão está sendo feita: colisao.get_collider().name

Nó para criação de texto: Label

Caminho para alterar sobreposição dos elementos na tela: Inspector -> CanvasItem -> Ordering -> Z index 

Método para executar funções apenas quando forem possíveis de se executar: @onready

Caminho para emitir sinais: Selecione o nó -> Inspector -> Sinais -> Selecione o sinal desejado -> Conectar -> Selecione o nó que contém o script que irá executar a função após o sinal emitido 

Nó para marcar posições no jogo: Marker2D

Atalho para duplicar nó selecionado: Crtl D

Nó para marcar intervalos de tempo dentro do jogo, útil para desencadear ações: Timer
- Para acionar um evento quando o timer termina, é necessário emitir o sinal timeout()

Nó que notifica quando o objeto entra ou sai da visualização: VisibleOnScreenNotifier2D

Caso seja necessário, por exemplo, gerar objetos de maneira dinâmica, eles não podem ser instaciados à cena principal do jogo como de costume, precisam ser pré-carregados através de código
